## How to publish
1. Download `plant-zoo.rbxl` from the latest GitHub Actions run (Artifacts), or run
   `rojo build games/plant-zoo -o plant-zoo.rbxl`.
2. Open it in Roblox Studio → File → Publish to Roblox.
3. Game Settings → Security → turn on **Studio Access to API Services** (for saving).
