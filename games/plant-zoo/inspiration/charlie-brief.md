# Create a Roblox Game Inspired by Plant Zoo 2nd Generation

Act as an expert Roblox game developer, Lua programmer, game designer, and UI/UX designer.

I want you to create a complete Roblox game inspired by Plant Zoo 2nd Generation. The game should capture the addictive gameplay loop of collecting creatures/plants, growing your collection, earning money, upgrading your zoo, and showing off your progress to other players.

IMPORTANT: Do not copy copyrighted assets, maps, branding, or proprietary code. Create original assets and mechanics inspired by the genre.

## 1. Core Gameplay
Players start with a small, empty zoo and a limited amount of starting money.

Players should be able to:
- Purchase seeds, plants, and creatures.
- Place plants and creatures inside their zoo.
- Watch plants grow through multiple stages.
- Collect money from visitors and zoo exhibits.
- Discover rare and legendary species.
- Expand their zoo with additional land.
- Upgrade their plants, creatures, and exhibits.
- Rebirth/prestige to gain permanent bonuses.
- Visit other players' zoos.
- Trade collectible species with other players.

## 2. Rarity System
Create a rarity system with the following tiers:

- Common
- Uncommon
- Rare
- Epic
- Legendary
- Mythical
- Secret

Higher rarity species should be harder to obtain and generate more income.

Add unique appearances, animations, and special visual effects for rare species.

## 3. Growing System
Every plant should have:
- A growth timer.
- Multiple growth stages.
- A selling value.
- An income value.
- A rarity.
- A unique appearance.

Players should be able to water and upgrade plants to speed up growth.

## 4. Economy
Create a balanced in-game economy.

Players earn money through:
- Zoo visitors.
- Plant production.
- Creature exhibits.
- Selling collectibles.
- Daily rewards.
- Quests and achievements.

Add multiple currencies if appropriate, including coins and premium currency.

## 5. Zoo Building
Create a building system that lets players:
- Place exhibits.
- Place plants and decorations.
- Move and rotate objects.
- Expand their zoo.
- Customize paths and scenery.
- Create their own unique zoo layout.

## 6. Multiplayer
The game must support multiple players in the same server.

Include:
- Player zoo plots.
- Visiting other players.
- Trading.
- Leaderboards.
- Global announcements for rare discoveries.
- Multiplayer events.

Make sure all important gameplay data is server-authoritative to prevent exploiting.

## 7. User Interface
Create a polished, modern Roblox UI.

Include:
- Money display.
- Inventory.
- Shop.
- Collection index.
- Building menu.
- Upgrade menu.
- Trading interface.
- Daily rewards.
- Settings.
- Quest tracker.

The UI should look professional, colorful, clean, and easy to navigate on both PC and mobile.

## 8. Progression
Add:
- Player levels.
- Zoo levels.
- Unlockable areas.
- New seeds and species.
- Daily quests.
- Achievements.
- Rebirth system.
- Limited-time events.

Make progression rewarding without making the game too easy.

## 9. Visual Style
Use a colorful, vibrant, cartoony Roblox art style.

Include:
- Detailed plants.
- Animated creatures.
- Beautiful environments.
- Particle effects.
- Smooth animations.
- Day/night cycles.
- Ambient sounds.
- Satisfying collection effects.

## 10. Technical Requirements
Build the game using Roblox Studio and Luau.

Use:
- ServerScriptService for server logic.
- ReplicatedStorage for shared modules and RemoteEvents.
- StarterGui for UI.
- StarterPlayer for player controls.
- DataStoreService for saving player data.
- ModuleScripts for reusable systems.

Requirements:
- Secure server-side validation.
- Data saving and loading.
- Automatic saving.
- Error handling.
- Organized and modular code.
- Optimized performance.
- Mobile and PC support.
