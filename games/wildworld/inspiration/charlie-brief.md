# Charlie's brief — Wildworld

Full master spec: `master-spec.md` (this folder). Use as high-level direction; MVP scope = section 24.

Charlie's notes:
- Build one system at a time. Priorities: 1) creature AI (move, eat, wander, interact), 2) building (players build their own parks), 3) genetics (breeding gives genuinely interesting offspring), 4) saving (never lose collections/parks), 5) secure multiplayer (trading + visiting).
- NO free models for creatures. Original creature models only (built in code from parts/meshes) — they're the game's identity.
- Ultimate goal: a player joins with an empty park, discovers a rare creature nobody else has, breeds it into a new genetic variation, and builds an amazing habitat to show it off.
- Visual focus: cute colorful original fantasy animals; beautiful habitats (waterfalls, forests, enclosures); biomes; glowing/crystal/golden/albino mutations; paths/fences/decor/shops; polished collection/genetics/inventory/park UI; wild encounters + discovery spots.
